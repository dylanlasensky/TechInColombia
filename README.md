# Tech in Colombia

A digital portfolio by Dylan Lasensky for **RFLA 300: Colombian Culture in Motion** at Rollins College, Fall 2026.

Website: [techincolombia.com](https://techincolombia.com)

## About the project

This project looks at how technology is changing everyday life in Colombia and what it could mean for the country’s future. It explores education, internet access, digital payments, small businesses, cybersecurity, and cultural representation.

The guiding question is: **How is technology changing everyday life in Colombia? What could it mean for the country’s future?**

The portfolio connects the research to my Computer Science major and my work as a cybersecurity analyst. It also reflects on my plans to attend Crummer for a STEM designated MBA and move into the business side of technology.

## Portfolio pages

- **Home:** The topic, why I chose it, and the guiding question.
- **Bibliography:** Ten annotated sources with APA citations. Six are scholarly, three are organizational, and one is a documentary.
- **Gallery:** Ten cultural artifacts with images, analysis, credits, and connections to the research.
- **Connections:** How the topic relates to education, economics, and political science.
- **My path:** A personal and professional reflection connecting the topic to my studies and career plans.

## Run locally

Open `public/index.html` in a browser. No installation is required. Keep the files and assets together.

You can also serve the website from the repository root:

```sh
python3 -m http.server 8046 --directory public
```

Then open http://localhost:8046. The pages and images work offline. Research links and source videos require internet access.

## Website files

The site uses plain HTML, CSS, and JavaScript. All website files are in `public/`. There are no packages to install or build commands to run.

## Deployment

The site is designed for Cloudflare Pages with GitHub integration:

- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `public`
- Custom domain: `techincolombia.com`

Push website changes to `main` to trigger a new deployment once the Cloudflare integration is connected.
